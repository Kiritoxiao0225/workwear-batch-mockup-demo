## 本地运行

使用 Node 22，先在仓库根目录 `npm ci`，然后：

```sh
npm run batch:dev
# 可选：加载已审阅的真实参考图 D02，路径指向包含 design-cases/D02/reference-1.jpg 的 review 目录
npm run batch:dev -- /absolute/path/to/review
```

打开 `http://127.0.0.1:3196/batch-mockup`。默认无外部参考图时仍有两行中文案例。端口可用 `BATCH_LOCAL_PORT` / `BATCH_LOCAL_DB_PORT` 覆盖（默认 3196 / 55448）。启动脚本只向子进程传入本地配置，不读取生产 `.env`。Web 与 PostgreSQL 都只监听回环地址。

实际文件与本地数据库保存在根目录 `output/batch-mockup-local/`，已被 Git 忽略；随机本地数据库密码文件权限 0600。重启不会清空图稿、步骤与版本。Ctrl+C 停止本次 Web、Worker、PostgreSQL。不要把此运行目录打包上传。

此目录是独立 Next 应用，避免加载旧业务的根布局和会话组件；依赖安装与版本锁定仍以父仓库 `package-lock.json` 为准，不在这里另建依赖树。
