导航 → **成衣效果图**（`/garment-mockup`）→ 从商品素材库选衣服或本地上传 → 添加 Logo / 文字 → 拖动、缩放、定位、标注 → 保存 / 导出。图稿生成页的结果可点击“用于成衣效果图”。工程支持自动保存、历史恢复、另存副本和账号内作品列表。

- 去背景改为同步接口 `POST /api/garment-mockup/cutouts`：浏览器直传图片字节，Web 当场返回透明 PNG；原图与结果在响应后保存（`after()`），保存作品不依赖这一步。顺序：同租户同图缓存 → 自带透明直接使用 → 纯色底且内部没有同色区域时本地去底（仅自动模式）→ 火山 `saliency_seg` → 明确失败或超时换美图图形抠图。一次任务最多调用两家，用户只扣一次；「图形精细」优先美图，「标准」优先火山，明确选择时跳过本地纯色底。旧 `jobs` 队列的 cutout 保留给未刷新的页面。
