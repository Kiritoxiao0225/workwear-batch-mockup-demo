## 0. 一句话

把一个「单工作区 + 全员共用一个账号」的内部工具，改成「一账号一租户 + 手机号登录 + 积分计费」的对外平台。
**同时不能影响 `/wps-production` 这条正在给客户交付的链路。**

## 1. 五分钟跑起来

```bash
npm install
npm run local          # 内嵌 PostgreSQL + Next，端口 3001
```

打开 `http://127.0.0.1:3001`，会跳转登录页。

| 登录方式 | 凭据 |
|---|---|
| 手机号验证码 | 任意 `138xxxxxxxx`；**验证码打印在运行 `npm run local` 的终端** |
| 邮箱密码（管理员） | 见 `data/catalog-local/credentials.json` |

本地是**独立空库**，不是生产数据。启动时会主动清空 `.env.local` 里的数据库 CA 证书与 WPS 凭据，
避免本地随手一点打到线上。要在本地连真实 WPS：

```bash
CATALOG_LOCAL_AUTH=1 CATALOG_LOCAL_PORT=3001 CATALOG_LOCAL_WPS=1 npx tsx scripts/catalog-local.ts
```

## 4. 数据库规则

完整说明见 `docs/database.md`。三条要点：

1. **只有一个生产库**（Zeabur），其余都是可随时删除的副本
2. 生产库**目前只跑到 016**，017–020 尚未执行
3. `catalog:restore` **绝不对生产库执行**（它要求空库，会拒绝）

### 生产迁移的执行顺序

```bash
# 1. 采集基线
npx tsx scripts/migration-baseline.ts output/<日期>/before.json

# 2. 备份（约 73 秒）
npm run catalog:backup -- "$(pwd)/output/<日期>/backup-before.json"

# 3. 执行
npm run catalog:migrate

# 4. 再采基线并比对
npx tsx scripts/migration-baseline.ts output/<日期>/after.json
```

**比对判据**：计数逐项相同；四项指纹中 `catalog` **必须完全一致**
（019 只给款式表加列、不改数据，变了就说明写错了，立即回滚）。

> 已备好的材料在 `output/migrate-20260921/`：`before.json` 与 `backup-before.json`（SHA `7b770c08…`）。
> 若已过较久，重新采集一次基线再执行。

### 不可逆点

019 会 `DROP` 并重建唯一约束：

```
garment_styles: (source_namespace, style_code) → (tenant_id, source_namespace, style_code)
import_batches: (manifest_hash)                → (tenant_id, manifest_hash)
```

执行后回滚代码也恢复不了行为——旧 `importCatalogAsset` 的 `ON CONFLICT` 目标已不存在。
**019 必须与对应代码同一次发布。**

## 6. 已知的坑（都已修，别再踩）

| 坑 | 症状 | 修法 |
|---|---|---|
| 迁移在**非空库**上失败 | `pending trigger events` | 回填后、ALTER 前加 `SET CONSTRAINTS ALL IMMEDIATE` |
| 备份漏表导致**恢复后无人能登录** | 凭据在 `user_identities`，不在备份清单 | 新增表必须同步加进 `catalog-backup.ts` 的 `TABLES` |
| bigint 精度丢失 | 配额用 bigint 最大值，JSON 往返后溢出 | 金额/配额不得超过 `Number.MAX_SAFE_INTEGER` |
| 新用户一上传就 403 | 建号事务漏建 `tenant_usage` | 建号必须同事务创建 usage 与 credit account |
| 页面 3 新图全部 404 | 加文件鉴权后 `saveProductionFile` 不登记引用 | 引用登记放在 `saveProductionFile` 内部，默认内部租户 |
| `delete process.env.X` 压不住 `.env.local` | Next 子进程会把值读回来 | 显式赋一个非目标值，别用 delete |
| 本地库被强制 TLS | `.env.local` 的 CA 证书被子进程读到 | 本地脚本显式清空 |
| 备份被语句超时掐断 | 大表中途失败 | `SET LOCAL statement_timeout = '15min'` |
